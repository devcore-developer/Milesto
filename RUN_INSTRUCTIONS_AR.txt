# تطبيق My List — دليل التشغيل

## الطريقة الأسهل (مش محتاج تعمل أي حاجة من اللي تحت)
التطبيق شغال بالفعل أونلاين. افتح المحادثة واضغط زر "المعاينة / Preview" عشان تفتح التطبيق مباشرة.

أول مرة تفتحه: هتلاقي شاشة "إعداد الحساب" — اكتب اسمك وإيميلك وكلمة سر واضغط إنشاء، وخلاص، حسابك هيبقى محفوظ.

---

## لو عايز تشغّله على جهازك الشخصي (اختياري)

المتطلبات: تثبيت Node.js من nodejs.org (نسخة LTS)

افتح التيرمينال (CMD) في فولدر المشروع ونفّذ الأوامر دي واحدة واحدة:

1) تثبيت المكتبات:
   npm install

2) إنشاء قاعدة البيانات:
   npx prisma db push

3) تشغيل التطبيق:
   npm run dev

4) افتح المتصفح على:  http://localhost:3000

---

## معلومات سريعة عن التطبيق

- أول حساب تعمله هو حساب المالك الوحيد (مفيش تسجيل لحد تاني).
- اللغة: عربي / إنجليزي — بتغيرها من صفحة الإعدادات (Settings).
- العملة الافتراضية: جنيه مصري (EGP) — هتستخدم في الفواتير بالمراحل الجاية.
- المراحل المتبقية: المشاريع، التقويم والإشعارات، العملاء والمالية، الفواتير، ملفات PDF، اللمسات الأخيرة.
