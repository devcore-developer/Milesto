# Milesto

A premium project execution and analytics workspace.

## Phase 1 — Design System & App Shell

Phase 1 establishes:
- A cohesive visual identity (deep navy sidebar, soft blue accent, semantic status colors, refined neutrals).
- Design tokens (colors, typography, radii, shadows, status) via CSS variables + Tailwind.
- Reusable UI primitives (buttons, inputs, badges, cards, tooltips, dropdowns, skeletons, tables, etc.).
- Reusable chart components built on Recharts (line, bar, area, donut) with shared tooltip + legend styling.
- A responsive application shell: desktop sidebar, mobile drawer, sticky topbar with search, notifications, and user menu.
- A comprehensive design-system showcase at `/design-system`.
